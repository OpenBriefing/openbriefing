# openbriefing

Tools for the [Open Briefing Standard (OBS)](https://openbriefingstandard.org). OBS is how a publisher states how their content should be summarized and presented when software consumes it.

**This is a draft placeholder.** Version 1.0.0 will include the reference parser and the `openbriefing` command, with `check`, `generate`, `preview`, `backfill`, `review` and a Ghost integration. Follow progress at [github.com/OpenBriefing/openbriefing](https://github.com/OpenBriefing/openbriefing).
